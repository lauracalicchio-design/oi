# 🚡 Desafio do Bondinho em Python

Projeto desenvolvido como solução para o desafio de controle de capacidade de excursão em um bondinho utilizando a linguagem Python.

## 📌 Sobre o Projeto

O programa calcula se o grupo de passageiros de uma excursão consegue realizar o passeio no bondinho em uma única viagem, respeitando o limite máximo de lotação.

### Regras do Desafio Adicional:
* **Capacidade Máxima do Bondinho:** 30 pessoas.
* **Professores Confirmados:** 8 pessoas (valor fixo).
* **Alunos e Monitores:** Valores fornecidos pelo usuário via terminal/input.

## 🚀 Tecnologias Utilizadas

* **Python 3**
* **Google Colab** (ambiente de desenvolvimento inicial)

## 🛠️ Como Executar o Código

1. Certifique-se de ter o Python 3 instalado em sua máquina.
2. Clone este repositório ou baixe o arquivo `desafio_bondinho.py`.
3. Abra o terminal e execute o comando:

```bash
python desafio_bondinho.py
